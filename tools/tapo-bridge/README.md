# Мост Tapo → Домовой

Опрашивает умную розетку с ваттметром (TP-Link Tapo **P110** / P115) в домашней
сети и шлёт замеры в приложение.

## Зачем нужен отдельный компьютер

Это главное, что стоит понять до покупки чего-либо ещё.

Розетка отвечает **только внутри локальной сети**, по `http` и без
CORS-заголовков. Страница приложения открыта по `https` и находится снаружи —
она до розетки не достучится никогда. Это не чинится настройкой браузера или
роутера: устройство просто не рассчитано на то, чтобы с ним разговаривала
веб-страница.

Поэтому в квартире должно быть что-то всегда включённое, что умеет запускать
Python:

- Raspberry Pi (любой, вплоть до Zero 2 W),
- мини-ПК или домашний сервер,
- NAS с поддержкой Python,
- старый ноутбук с закрытой крышкой.

Расход электричества у самого Pi — около 2–3 Вт, на фоне измеряемой техники
это незаметно.

> **Про отключения света.** Если мост выключится вместе со светом, ничего не
> потеряется безвозвратно: накопительные счётчики ведёт сама розетка, и после
> возвращения связи месячный расход приедет правильным. Пропадут только точки
> на графике за время простоя.

## Почему протокол не написан здесь руками

TP-Link не публикует локальный API. Протокол (KLAP) восстановлен сообществом,
менялся вместе с прошивками и различается у линеек Kasa и Tapo. Реализация «по
памяти», без спецификации и без устройства под рукой, почти наверняка не
заработала бы, а отлаживать байты AES пришлось бы владельцу.

Поэтому транспортом занимается [python-kasa](https://github.com/python-kasa/python-kasa) —
живая библиотека, которую гоняют на реальных устройствах и которая сама
разбирается и с KLAP, и со старым протоколом. Всё остальное (опрос, единицы,
устойчивость к обрывам, отправка) — в `tapo_bridge.py`, 250 строк, которые
можно прочитать целиком.

## Установка

Розетка должна быть уже настроена в приложении Tapo и иметь **постоянный адрес**
в сети — закрепите его в роутере по MAC-адресу, иначе после перезагрузки
роутера мост потеряет розетку.

```bash
python3 -m venv ~/tapo-bridge-venv
~/tapo-bridge-venv/bin/pip install python-kasa
```

## Проверка

Сначала — один замер, без отправки куда-либо:

```bash
export TAPO_EMAIL='почта@от.tapo'      # те же, что в приложении Tapo
export TAPO_PASSWORD='пароль'
export TAPO_HOST='192.168.0.50'        # адрес розетки в сети

~/tapo-bridge-venv/bin/python tapo_bridge.py --once
```

Выведет что-то вроде:

```
розетка: Чайник (device_id 802E...)
первый замер: {"device_id": "802E...", "name": "Чайник",
               "power_w": 1847.2, "today_wh": 412.0, "month_wh": 8931.0}
```

**Сверьте эти числа с приложением Tapo.** Это единственный способ убедиться,
что единицы совпали: мощность в ваттах, расход в ватт-часах. Если мощность
выглядит в тысячу раз больше правды, мост откажется работать сам — но лучше
увидеть это глазами.

## Постоянная работа

Ключ выдаёт приложение: **Энергия → Подключить розетку**. Показывается он один
раз — в базе хранится только отпечаток.

```bash
sudo tee /etc/systemd/system/tapo-bridge.service > /dev/null <<'UNIT'
[Unit]
Description=Мост Tapo -> Домовой
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/tapo-bridge
Environment=TAPO_EMAIL=почта@от.tapo
Environment=TAPO_PASSWORD=пароль
Environment=TAPO_HOST=192.168.0.50
Environment=DOMOVOY_INGEST_URL=https://ВАШ-ПРОЕКТ.supabase.co/functions/v1/plug-ingest
Environment=DOMOVOY_TOKEN=dmv_...
ExecStart=/home/pi/tapo-bridge-venv/bin/python /home/pi/tapo-bridge/tapo_bridge.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
UNIT

sudo systemctl daemon-reload
sudo systemctl enable --now tapo-bridge
journalctl -u tapo-bridge -f
```

Файл юнита содержит пароль — закройте его от посторонних:

```bash
sudo chmod 600 /etc/systemd/system/tapo-bridge.service
```

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TAPO_EMAIL`, `TAPO_PASSWORD` | — | учётка Tapo, обязательны |
| `TAPO_HOST` | — | адрес розетки в локальной сети, обязателен |
| `DOMOVOY_INGEST_URL` | — | адрес приёмника, из приложения |
| `DOMOVOY_TOKEN` | — | ключ, из приложения |
| `POLL_SECONDS` | `5` | как часто спрашивать розетку (локально, почти бесплатно) |
| `HEARTBEAT_SECONDS` | `60` | как часто отправлять, даже если ничего не изменилось |
| `CHANGE_ABS_W` | `5` | скачок в ваттах, на который реагируем сразу |
| `CHANGE_REL` | `0.1` | то же в долях от прошлого значения |

### Почему отправка редкая, а опрос частый

Опрос розетки — локальный запрос, он ничего не стоит. Отправка — вызов
серверной функции, а их в бесплатном тарифе Supabase 500 тысяч в месяц. Пуш
каждые 10 секунд — это 260 тысяч в месяц **на одну розетку**, то есть половина
лимита за одну железку.

Поэтому мост шлёт данные, когда мощность заметно изменилась (включили чайник —
увидите почти сразу), а в покое ограничивается heartbeat раз в минуту. При
настройках по умолчанию выходит около 45 тысяч вызовов в месяц на розетку.

Если розеток много или хочется реже — увеличьте `HEARTBEAT_SECONDS`.

## Если не работает

| Симптом | Причина |
|---|---|
| `Нужен TAPO_HOST` | не заданы переменные окружения |
| ошибка авторизации | почта и пароль — именно от аккаунта Tapo, не от Wi-Fi |
| `У устройства нет модуля замера энергии` | это P100 без ваттметра, а не P110 |
| розетка «недоступна» после перезагрузки роутера | адрес сменился, закрепите его по MAC |
| `Ключ недействителен` | ключ отозван или скопирован не полностью |
| мощность неправдоподобна | обновите `python-kasa`, сверьте с приложением Tapo |
