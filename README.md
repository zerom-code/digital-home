# Домовой

PWA, которая знает всё о квартире.

Одно место, где про каждую вещь в доме известно: что это, где стоит, когда
куплено, до когда гарантия, где инструкция, кто чинил и сколько электричества
она съедает. Общее для всей семьи, работает без интернета, ставится на
домашний экран iPhone и Android как обычное приложение.

```
Квартира
├── Кухня
│   ├── Холодильник
│   │   ├── куплен: 2024
│   │   ├── гарантия: до 2027
│   │   ├── инструкция
│   │   └── сервис
│   └── Посудомойка
├── Ванная
│   └── Бойлер
└── Гостиная
    └── TV
```

## Три обещания пользователю

1. **Найду за 5 секунд** — инструкция, серийник, телефон мастера, дата покупки.
2. **Узнаю заранее** — гарантия истекает через месяц, фильтр пора менять,
   бойлеру нужно ТО.
3. **Увижу, куда уходят деньги** — сколько кВт·ч и гривен ест каждая железка.

## Статус

**Фаза 2 — документы, гарантии, задачи.** Работает:

- вход по коду на почту, семья с приглашениями по ссылке, роли;
- дерево «дом → комната → вещь», карточка со всеми полями
  (обязательное — только название), фотографии, поиск по всему дому;
- документы: инструкции, чеки и гарантийники файлом или ссылкой;
- задачи из гарантий, интервалов ТО и расходников; повторяющиеся заводят
  следующую сами;
- push-напоминания за месяц до конца гарантии;
- полноценный офлайн: чтение из кеша и очередь записи с отправкой при
  появлении сети;
- распознавание заводской таблички с фото — модель, серийник и мощность
  заполняются сами.

Энергия — следующая фаза, см. [docs/06-roadmap.md](docs/06-roadmap.md).

## Запуск

```bash
cp .env.example .env      # заполнить VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm install
npm run icons             # иконки для домашнего экрана
npm run dev
```

Развёртывание с нуля, включая создание проекта Supabase и накат миграций, —
в [docs/09-setup.md](docs/09-setup.md).

### Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run typecheck` | Только типы |
| `npm run test` | Юнит-тесты (vitest) |
| `npm run icons` | Генерация PNG-иконок и favicon |
| `npm run db:seed` | `data/categories.ru.json` → `supabase/seed/categories.sql` |
| `npm run db:test` | Миграции и тесты RLS на локальном PostgreSQL |

`npm run db:test` требует только PostgreSQL 16+ — ни Docker, ни стека
Supabase: схемы `auth` и `storage` подменяет шим. Прогоняет 91 проверку —
изоляция семей, роли, триггеры целостности, приглашения, генерация задач из
гарантий и ТО, повторяющиеся задачи, очередь уведомлений и чистка корзины.

## Стек

**Клиент:** Vite + React + TypeScript, Tailwind v4, TanStack Query с персистом
в IndexedDB, свой service worker на Workbox, i18next. Компоненты свои, на
нативном HTML — почему так, в [ADR-013](docs/07-decisions.md).

**Бэкенд:** Supabase — Postgres с Row Level Security, Auth, Storage, Realtime,
Edge Functions, pg_cron. RLS является единственным слоем авторизации: клиент
ходит в базу напрямую.

**ИИ:** gpt-4o-mini через Edge Function для распознавания шильдиков. Ключ
живёт только на сервере, модель возвращает черновик формы и ничего не пишет
в базу сама ([ADR-008](docs/07-decisions.md)).

## Устройство репозитория

```
src/
├── app/            роутинг, каркас, нижняя панель
├── components/ui/  свой UI-кит
├── features/       auth, household, home, items, documents, tasks,
│                   search, onboarding, ai, pwa, more
├── lib/            supabase, query, outbox, i18n, поиск, дерево, гарантии
└── sw.ts           service worker: кеш, push, переход по уведомлению

supabase/
├── migrations/     схема, RLS, RPC, хранилище, задачи и push
├── functions/      send-push, ai-extract-nameplate
├── seed/           справочник категорий (генерируется)
└── tests/          шим Supabase и тесты изоляции семей

data/               справочник техники и шаблоны квартир
scripts/            генераторы seed и иконок, прогон тестов БД
docs/               проектная документация
```
