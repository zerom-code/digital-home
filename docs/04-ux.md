# 04. Интерфейс

## Проектное ограничение

Приложением пользуются два очень разных человека:

- **зумер** — быстро, одной рукой, ожидает жестов и скорости;
- **его мама** — редко, с конкретным вопросом, не будет ничего осваивать.

Правило разрешения конфликта: **скорость для первого не должна создавать
скрытых механик для второй.** Жест — всегда дополнение к видимой кнопке, а не
замена ей.

Проверочный вопрос к любому экрану: *человек, впервые открывший приложение,
понимает, что здесь делать, без единого слова объяснений?* Если нет — экран
спроектирован неверно.

---

## Информационная архитектура

Нижняя панель, четыре вкладки и крупная кнопка «+» по центру.

```
🏠 Дом        ✅ Задачи      ➕      ⚡ Энергия     👤 Ещё
```

| Вкладка | Что там |
|---|---|
| **Дом** | Комнаты и вещи, поиск. Главный экран. |
| **Задачи** | Гарантии на исходе, ТО, расходники — всё, что горит |
| **➕** | Добавить вещь / комнату / документ / показания счётчика |
| **Энергия** | Сколько ест квартира и кто именно |
| **Ещё** | Семья, тарифы, документы, «что делать, если», настройки, экспорт |

Больше четырёх вкладок не будет. Всё, что не помещается, уходит в «Ещё» —
это нормальное место для того, что открывают раз в месяц.

---

## Экран «Дом»

Не файловый менеджер. Крупные карточки комнат с иконкой и фотографией; под
каждой — счётчик вещей и предупреждение, если внутри что-то горит
(«гарантия истекает»).

```
┌─────────────────────────────────────┐
│  🔍  Найти что угодно                │
├─────────────────────────────────────┤
│  ┌───────────────┐ ┌───────────────┐ │
│  │  🍳  Кухня     │ │  🛁  Ванная    │ │
│  │  8 вещей       │ │  3 вещи        │ │
│  │  ⚠ 1 гарантия  │ │                │ │
│  └───────────────┘ └───────────────┘ │
│  ┌───────────────┐ ┌───────────────┐ │
│  │  🛋  Гостиная  │ │  ➕ Добавить   │ │
│  │  5 вещей       │ │    комнату     │ │
│  └───────────────┘ └───────────────┘ │
└─────────────────────────────────────┘
```

Тап по комнате → сетка вещей с фотографиями. Фото важнее текста: человек
узнаёт свой холодильник по картинке быстрее, чем читает «Samsung RB37».

**Поиск сверху ищет везде сразу** — по названиям, моделям, серийникам,
заметкам и содержимому инструкций. Это самый частый сценарий возврата в
приложение, поэтому поле видно всегда, а не прячется за иконкой.

## Карточка вещи

Фотография на всю ширину, крупное название, дальше — блоки:

```
┌─────────────────────────────────────┐
│         [ фото холодильника ]        │
│                                      │
│  Холодильник                         │
│  Samsung RB37 · Кухня                │
├─────────────────────────────────────┤
│  🛡  Гарантия                         │
│      действует ещё 1 год 4 месяца    │
├─────────────────────────────────────┤
│  ⚡  Энергия                          │
│      ≈ 142 грн/мес                   │
├─────────────────────────────────────┤
│  📄  Документы                        │
│      Инструкция · Чек                │
├─────────────────────────────────────┤
│  🔧  Сервис                           │
│      Пока не чинили                  │
│      [ Записать ремонт ]             │
└─────────────────────────────────────┘
```

**Незаполненные блоки не прячутся.** Они показываются как приглашение с одной
кнопкой:

```
┌─────────────────────────────────────┐
│  🛡  Гарантия                         │
│      Добавь дату покупки — посчитаю,  │
│      действует ли она                │
│      [ Указать дату ]                │
└─────────────────────────────────────┘
```

Это и есть «лестница ценности» из [01-features.md](01-features.md) в
интерфейсном виде: не абстрактный процент заполненности, а конкретное
предложение с конкретной выгодой.

## Добавление вещи

Bottom sheet. Поле названия, кнопка камеры, выбор комнаты.
**Кнопка «Готово» активна сразу** — как только введено название.

```
┌─────────────────────────────────────┐
│  Что добавляем?                      │
│                                      │
│  ┌─────────────────────────────────┐ │
│  │ Название                        │ │
│  └─────────────────────────────────┘ │
│                                      │
│  [ 📷 Сфотографировать ]             │
│                                      │
│  Где стоит:  [ Кухня ▾ ]             │
│                                      │
│           [    Готово    ]           │
└─────────────────────────────────────┘
```

После сохранения — **необязательный** экран «Добавить ещё?» с тремя
карточками (дата покупки / модель / документы), а не форма из пятнадцати
полей. Закрыть его можно одним тапом, и это не воспринимается как отказ.

## Экран «Энергия»

Сверху — одно крупное число в гривнах за месяц. Ниже — список вещей,
отсортированный по стоимости, с полосками.

```
┌─────────────────────────────────────┐
│           ≈ 1 037 грн                │
│           в месяц                    │
│                                      │
│  Бойлер          ████████████  757 ₴ │
│  Холодильник     ██            142 ₴ │
│  Стиралка        █              60 ₴ │
│  Телевизор       ▌              53 ₴ │
│  Роутер          ▏              25 ₴ │
│                                      │
│  ─────────────────────────────────── │
│  Показания счётчика за июль          │
│  Расчёт 240 · Факт 290 кВт·ч         │
│  50 кВт·ч не объяснены               │
│                     [ Разобраться ]  │
└─────────────────────────────────────┘
```

**Гривны на первом плане, кВт·ч — вторым.** Деньги понятны всем; киловатт-часы
понятны не всем.

## Правила, которые делают интерфейс «маминым»

**1. Один экран — один вопрос.** Формы разрезаны на шаги, а не свалены в одну
простыню.

**2. Человеческий язык.** Не «Атрибуты сущности», а «Что мы знаем о
холодильнике». Не «Ошибка синхронизации», а «Сохраним, когда появится
интернет». Слова «сущность», «синхронизация», «валидация» в интерфейсе
запрещены.

**3. Крупно по умолчанию.** Базовый кегль 17px, зоны нажатия не меньше 48px,
контраст не ниже 4.5:1. В настройках — переключатель «Крупный текст»
(масштаб 1.25), а не только системный.

**4. Отмена вместо подтверждения.** Никаких «Вы уверены?». Удалил → тост
«Удалено · Отменить» на 5 секунд, плюс корзина на 30 дней. Диалог
подтверждения останавливает всех, а защищает только от опечатки; отмена
защищает лучше и никого не тормозит.

**5. Ничего не теряется.** Черновик формы живёт в локальном хранилище. Закрыл
приложение на полуслове — вернулся ровно туда же.

**6. Офлайн — не ошибка, а режим.** Не красный экран «Нет соединения», а
спокойная строчка в шапке: «Работаем офлайн · 2 изменения отправим позже».

**7. Пустые состояния учат.** Не «Нет данных», а «Здесь пока пусто. Начни с
кухни — там обычно больше всего техники» и кнопка.

**8. Никаких модалок поверх модалок.** Только bottom sheets, и не глубже
одного уровня.

**9. Тёмная тема** и уважение к `prefers-reduced-motion`.

**10. QR-наклейка как обходной путь мимо навигации.** Маме не обязательно
осваивать приложение: она наводит камеру на стикер и сразу попадает в нужную
карточку.

## Онбординг

Не больше четырёх экранов. Цель — довести до первой заполненной комнаты, а не
рассказать о возможностях.

**1. Зачем это нужно.** Одна фраза и картинка. Без карусели из шести слайдов.

**2. Вход.** Email-код, Google или Apple. Пароля нет — это меньше трения и
меньше поводов застрять.

**3. «Как называется твой дом?»** плюс выбор шаблона:

```
   [ 1-комнатная ]   [ 2-комнатная ]
   [ Свой дом    ]   [ Начну с нуля ]
```

Шаблон создаёт комнаты и типовые заглушки техники с уже проставленными
мощностями. Это главный выигрыш онбординга: квартира заполняется за шесть
тапов, а дальше человек правит, а не создаёт с нуля — редактировать
психологически легче.

**4. «Готово. Вот твоя квартира»** — уже с комнатами, с предложением добавить
первую вещь фотографией.

**Приглашение семьи на онбординг не выносим.** Звать людей в пустое
приложение бессмысленно; предложение появится позже, когда будет что
показывать.

---

## Доступность

- Все интерактивные элементы — не меньше 48×48px.
- Контраст текста не ниже 4.5:1, крупного — не ниже 3:1.
- Каждая иконка-кнопка имеет `aria-label`.
- Приложение полностью управляется с клавиатуры (важно для внешних клавиатур
  на планшетах и для скринридеров).
- Фокус виден всегда, `:focus-visible` не отключаем.
- Ни одно состояние не передаётся только цветом — рядом всегда иконка или
  текст.
- Формы — нативные `<input>` с правильными `type` и `inputmode`, чтобы на
  телефоне открывалась нужная клавиатура и работал автозаполнитель.
- Анимации отключаются при `prefers-reduced-motion: reduce`.

## Тон текстов

Дружелюбный, короткий, без канцелярита и без сюсюканья.

| Плохо | Хорошо |
|---|---|
| Ошибка валидации: поле обязательно | Как это назвать? |
| Данные отсутствуют | Здесь пока пусто |
| Синхронизация не удалась | Сохраним, когда появится интернет |
| Вы уверены, что хотите удалить? | Удалено · Отменить |
| Заполнено 40 % | Добавь дату покупки — посчитаю гарантию |
| Объект успешно создан | Готово |

Обращение — на «ты». Это сокращает дистанцию и хорошо ложится на образ
домового: приложение — свой в доме, а не служба поддержки.
